# Cams-Man

**Your go-to resource for camera reviews, comparisons, and buying guides.**

Live at [cams-man.com](https://cams-man.com).

## Overview

Cams-Man is a static website providing honest camera information to help photographers choose the right gear.  
It covers mirrorless, DSLR, compact, action, film, and medium-format cameras.

## Structure

| File        | Purpose                            |
|-------------|------------------------------------|
| `index.html`| Main page — reviews, categories, guides |
| `style.css` | Dark-theme responsive stylesheet   |
| `main.js`   | Mobile nav, live search/filter, scroll highlighting |

## Running locally

Open `index.html` in any modern browser, or serve with any static file server, e.g.:

```bash
npx serve .
```
